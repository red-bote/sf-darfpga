# Satans-Hollow-by-Dar

Basys 3 port of Satan's Hollow (Bally Midway MCR, 1981), original core by Dar
(darfpga@aol.fr), <http://darfpga.blogspot.fr>. Source:
`vhdl_satans_hollow_rev_0_2_2019_11_22.zip` (rev 0.2, 2019-11-22), `dloads/`. Basys 3 port
by Red~Bote. Dar's release notes: `README.txt` in the extracted archive.

## Status

Hardware-verified 2026-10-20: picture (31 kHz VGA), sound, MAME keyboard decoder,
JXADC joystick, buttons. DIP switches (sw12 cocktail, sw11 coin meters) wired 2026-10-20;
cocktail with sw12 up not individually reported (Dar marks it "KO atm"). Open items: none.

## Features (Basys 3)

- Video: native 31 kHz progressive or 15 kHz TV, generated by the core (no external
  scandoubler; the core drives `video_hs`/`video_vs`); sw13 up = 15 kHz TV (sw13 alone
  since 2026-09-29; previously sw13 XOR the F8 toggle).
- Keyboard: onboard USB-HID port, MAME default keys, decoded in the wrapper (2026-10-20,
  replaces `kbd_joystick`; F0 = release, E0 ignored).
- Joystick: Atari-style on Pmod JXADC, pins 1/2/3/7 = right/left/shield/fire, active low,
  pull-ups in the XDC.
- Audio: PmodAMP2 on Pmod JA pins 1/2/4; left channel of the core's stereo output;
  `separate_audio` tied `'0'` (mixed, 2026-10-20; was the F5 toggle).

Player 2 (cocktail inputs) mirrors player 1. JXADC4 unused. Mapping as the

## Switches

| Switch | Function | Down | Up |
|---|---|---|---|
| sw15 | audio | on | off |
| sw14 | amp gain | low | high |
| sw13 | display | 31 kHz VGA | 15 kHz TV |
| sw12 | `cocktail` | upright (Dar `'0'`) | cocktail (Dar: "KO atm") |
| sw11 | `coin_meters` | Dar `'0'` | `'1'` |

No game DIP bank at the core boundary; settings via the service menu (F2).

## Clocking

`clk_wiz_0`: 40.000 MHz (1 / 10.0 / 25.0), single domain; original 19.968 MHz main
crystal, 16 MHz SSIO sound board. Video H 31.546 kHz / V 60.09 Hz (31 kHz mode). Details:
`contrib/basys3/PORTING_SPEC.md` §2, `../CLOCK_CRYSTAL_CATALOG.md`.

## Required ROMs

`shollow.zip` (MAME romset, single set; `ROMZIP`, default `~/roms/shollow.zip`). Not
included. The set holds the SSIO PROM as `82s123.12d`; `prep_roms.sh` renames it to
`midssio_82s123.12d` (the `.bat` name). Generated PROM VHDL: `satans_hollow_cpu.vhd`,
`satans_hollow_sound_cpu.vhd`, `satans_hollow_bg_bits_1.vhd`,
`satans_hollow_bg_bits_2.vhd`, `satans_hollow_sp_bits.vhd`, `midssio_82s123.vhd`,
referenced in place by the project.
**Do not redistribute roms or anything generated from them.**

## Building

Requires gcc, unzip, Vivado 2020.2, openFPGALoader. `make help`; `make` (setup, project,
patch), `make check` (parse-only), `make bitstream`, `make load` (existing bit),
`make rebuild-load`, `make clean`. `make setup` runs `contrib/tools/setup_satans_hollow.sh`:
verify the `dloads/` archive (SHA-256), extract `vhdl_satans_hollow_rev_0_2_2019_11_22/`,
run `contrib/tools/prep_roms.sh` (romset pre/post-flight checks).

## Known issues

- Core-internal HDL 9-3240 CRITICAL WARNING (expression actual) at
  `rtl_dar/satans_hollow.vhd:934`, pre-existing in Dar's core; builds unaffected; left as is.

## Issues addressed for Basys 3

- Display mode on sw13 alone (2026-09-29); pristine `tv15Khz_mode <= not fn_toggle(7)`
  defaulted to 15 kHz.
- Keyboard on `clock_40`; the pristine 2 MHz `clock_kbd` was too slow for the onboard
  USB-HID host. Its `clock_div` counter remains as the PWM accumulator gate only.
- `btnD` drives `coin2` (the pristine top ties it low).
