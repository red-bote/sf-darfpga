# Kick-Midway-MCR-by-Dar

Basys 3 port of Kick (Midway MCR, 1981), original core by Dar (darfpga@aol.fr),
<http://darfpga.blogspot.fr>. Source: `vhdl_kick_rev_0_2_2019_11_22.zip` (rev 0.2,
2019-11-22), `dloads/`. Basys 3 port by Red~Bote. Dar's release notes: `README.txt` in the
extracted archive.

## Status

Hardware-verified 2026-10-20: picture (31 kHz VGA), sound, MAME keyboard decoder on
`clock_40`, JXADC joystick, buttons. Earlier: USB-HID keyboard, buttons and joystick
confirmed 2026-09-25. Open items: none.

## Features (Basys 3)

- Video: native 31 kHz progressive or 15 kHz TV, generated by the core (no external
  scandoubler); sw13 up = 15 kHz TV (since 2026-09-29; pristine: F8 toggle).
- Keyboard: onboard USB-HID port, MAME default keys, decoded in the wrapper (2026-10-20,
  replaces `kbd_joystick`; F0 = release, E0 ignored).
- Joystick: Atari-style on Pmod JXADC, pins 1/2/3/4/7 = right/left/down/up/fire, active
  low, pull-ups in the XDC.
- Audio: PmodAMP2 on Pmod JA pins 1/2/4; the core's stereo path, left channel out;
  `separate_audio` tied `'0'` (mixed, 2026-10-20; was the F5 toggle).

Player 2 mirrors player 1. JXADC3 unused. Mapping as the hardware-verified `rb-fpga/ref-repos`

## Switches

| Switch | Function | Down | Up |
|---|---|---|---|
| sw15 | audio | on | off |
| sw14 | amp gain | low | high |
| sw13 | display | 31 kHz VGA | 15 kHz TV |

No DIP inputs at the core boundary: settings come from the service menu (F2).

## IO mapping

| Basys 3 resource | Wrapper port | Function |
|---|---|---|
| clk (W5, 100 MHz) | `clk` | into `clk_wiz_0` |
| btnC / btnU / btnD / btnL / btnR | `btnC` ... `btnR` | reset / coin 1 / coin 2 / start 1 / start 2 |
| sw(15:13) | `sw` | see Switches |
| USB-HID C17 / B17 | `ps2_clk` / `ps2_dat` | keyboard |
| JXADC1-4, JXADC7 | `JXADC(0..4)` | joystick |
| JA1 / JA2 / JA4 | `O_PMODAMP2_AIN` / `_GAIN` / `_SHUTD` | audio (left channel) |
| VGA | `vgaRed/vgaGreen/vgaBlue(3:0)`, `vgaHsync`, `vgaVsync` | 4-4-4 RGB |

## Clocking

`clk_wiz_0`: 40.000 MHz (1 / 10.0 / 25.0), single domain; original 19.968 MHz main
crystal, 16 MHz SSIO sound board. Video H 31.546 kHz / V 60.09 Hz (31 kHz mode). Details:
`contrib/basys3/PORTING_SPEC.md` §2, `../CLOCK_CRYSTAL_CATALOG.md`.

## Required ROMs

`kick.zip` (MAME romset; `ROMZIP`, default `~/roms/kick.zip`). Not included.
`prep_roms.sh` concatenates the chip ROMs into `kick_cpu.bin`, `kick_sound_cpu.bin`,
`kick_sp_bits.bin` and generates `kick_cpu.vhd`, `kick_sound_cpu.vhd`,
`kick_bg_bits_1/2.vhd`, `kick_sp_bits.vhd`, `midssio_82s123.vhd`, referenced in place by
the project.
**Do not redistribute roms or anything generated from them.**

## Building

Requires gcc, unzip, Vivado 2020.2, openFPGALoader. `make help`; `make` (setup, project,
patch), `make check` (parse-only), `make bitstream`, `make load`. `make setup` runs
`contrib/tools/setup_kick.sh`: verify the `dloads/` archive (SHA-256), extract
`vhdl_kick_rev_0_2_2019_11_22/`, run `contrib/tools/prep_roms.sh`.

## Known issues

None.

## Issues addressed for Basys 3

- Display mode on sw13 instead of the F8 keyboard toggle (2026-09-29); also removes a
  power-on default to 15 kHz (`fn_toggle` has no reset in `kbd_joystick.vhd`).
- Keyboard on `clock_40`; the fabric `clock_kbd` (`clock_40`/6) is removed (2026-10-20).
- Reset held until the MMCM locks (2026-10-01).
