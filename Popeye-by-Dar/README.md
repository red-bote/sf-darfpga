# Popeye-by-Dar

Basys 3 port of Popeye (Nintendo, 1982), original core by Dar (darfpga@aol.fr),
<http://darfpga.blogspot.fr>. Source: `vhdl_popeye_rev_0_3_2020_01_27.zip` (rev 0.3,
2020-01-27), `dloads/`. Basys 3 port by Red~Bote. Dar's release notes: `README.txt` in the
extracted archive.

## Status

Hardware-verified 2026-10-20: picture (31 kHz VGA), sound, MAME keyboard decoder on
`clock_40`, JXADC joystick, buttons; DIP 1 coinage on sw11-8 hardware-checked 2026-10-21.
Earlier: USB-HID keyboard 2026-09-28. Open items: none.

## Features (Basys 3)

- Video: native 31 kHz progressive or 15 kHz TV, generated by the core (no external
  scandoubler); sw13 up = 15 kHz TV.
- Keyboard: onboard USB-HID port, MAME default keys, decoded in the wrapper (2026-10-20,
  replaces `kbd_joystick`; F0 = release, E0 ignored).
- Joystick: Atari-style on Pmod JXADC, pins 1/2/3/4/7 = right/left/down/up/fire, active
  low, pull-ups in the XDC.
- Audio: PmodAMP2 on Pmod JA pins 1/2/4, mono.
- CPU/AY rate fix: `contrib/code/popeye_clock_cnt2_width.patch` (2026-10-01) restores CPU
  f/10 = 4.032 MHz and AY f/20; the pristine 4-bit `clock_cnt2` never reloaded at 19 and ran
  about 25% fast (sound about 4 semitones sharp). `../CLOCKING_SPEC.md` 5.6.

## Switches

| Switch | Function | Down | Up |
|---|---|---|---|
| sw15 | audio | on | off |
| sw14 | amp gain | low | high |
| sw13 | display | 31 kHz VGA | 15 kHz TV |
| sw11-8 | DIP 1 (`sw1`) coinage, bits 3-0 | Dar's value | bit inverted |
| sw7-0 | DIP 2 (`sw2`): cocktail / music / bonus (2) / difficulty (2) / lives (2) | bit set in `not sw` (all down = `x"FF"`) | bit cleared |

DIP 2 is `not sw(7 downto 0)` (as rework, hardware 2026-10-19); Dar's DE10 value is
`"00111101"`. DIP 1 copyright (bits 6-5) and N.U. (bit 4) stay at Dar's value.

## Clocking

`clk_wiz_0`: 40.320 MHz (5 / 31.5 / 15.625), single domain; original 8.000 MHz crystal (CPU
4 MHz, AY 2 MHz). Video H 31.500 kHz / V 59.886 Hz. Details:
`contrib/basys3/PORTING_SPEC.md` §2, `../CLOCK_CRYSTAL_CATALOG.md`.

## Required ROMs

`popeye.zip` + `popeyeu.zip` (MAME romsets; `ROMZIP1` / `ROMZIP2`, defaults
`~/roms/popeye.zip`, `~/roms/popeyeu.zip`). Not included. `popeyeu` provides the
`7a`/`7b`/`7c`/`7e` ROMs absent from `popeye`. Generated PROM VHDL: `popeye_cpu.vhd`,
`popeye_cpu_protected.vhd`, `popeye_ch_bits.vhd`, `popeye_sp_bits_1..4.vhd`,
`popeye_ch_palette_rgb.vhd`, `popeye_sp_palette_gb.vhd`, `popeye_sp_palette_rg.vhd`,
`popeye_bg_palette_rgb.vhd`, referenced in place by the project.
**Do not redistribute roms or anything generated from them.**

## Building

Requires gcc, unzip, Vivado 2020.2, openFPGALoader. `make help`; `make` (setup, project,
patch), `make check` (parse-only), `make bitstream`, `make load`. `make setup` runs
`contrib/tools/setup_popeye.sh`: verify the `dloads/` archive (SHA-256), extract
`vhdl_popeye_rev_0_3_2020_01_27/`, apply `contrib/code/*.patch`, run
`contrib/tools/prep_roms.sh`.

## Issues addressed for Basys 3

- `rtl_dar/popeye.vhd`: 4-bit `clock_cnt2` compared with `"10011"` (19) never reloaded; CPU
  f/8, AY f/16 (+26%). Widened to 5 bits (`contrib/code/popeye_clock_cnt2_width.patch`).
- `rtl_mikej/ym_2149_linmix.vhd`: `p_rdata` (combinational read-back of `O_DA`) omits
  `ioa_inreg` and `iob_inreg` from its sensitivity list, so a port-input change left the
  read-back stale; both added (`contrib/code/popeye_linmix_sensitivity.patch`, `iob_inreg`
  2026-10-07).
- Keyboard on `clock_40`; the fabric `clock_kbd` (`clock_40`/6) is removed (2026-10-20).
