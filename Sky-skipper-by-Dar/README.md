# Sky-skipper-by-Dar

Basys 3 port of Sky Skipper (Nintendo, 1981), FPGA core by Dar (darfpga@aol.fr),
<http://darfpga.blogspot.fr>. Source: `vhdl_sky_skipper_rev_01_2020_01_28.zip` (rev 01,
2020-01-28), `dloads/`. Basys 3 port by Red~Bote. Dar's release notes: `README.txt` in the
extracted archive. Directory name uses a lowercase `s` (`Sky-skipper`).

## Status

Hardware-verified 2026-10-20: picture (31 kHz VGA), sound, MAME keyboard decoder, JXADC
joystick, buttons; DIP 2 on sw7-0 (not inverted, as rework, hardware 2026-10-19); DIP 1
coinage on sw11-8 hardware-checked 2026-10-21. Open items: none.

## Features (Basys 3)

- Video: native 31 kHz progressive or 15 kHz TV, generated by the core (no external
  scandoubler; the core drives `video_hs`/`video_vs`); sw13 up = 15 kHz TV (sw13 alone
  since 2026-09-29; previously sw13 XOR the F8 toggle).
- Keyboard: onboard USB-HID port, MAME default keys, decoded in the wrapper (2026-10-20,
  replaces `kbd_joystick`; F0 = release, E0 ignored).
- Joystick: Atari-style on Pmod JXADC, pins 1/2/3/4/7 = right/left/down/up/bomb, active
  low, pull-ups in the XDC.
- Audio: PmodAMP2 on Pmod JA pins 1/2/4, mono.
- CPU/AY rate fix: `contrib/code/sky_skipper_clock_cnt2_width.patch` (2026-10-01) restores
  CPU f/10 = 4.032 MHz and AY f/20; the pristine 4-bit `clock_cnt2` never reloaded at 19 and
  ran about 25% fast. `../CLOCKING_SPEC.md` 5.6.

Player 2 mirrors player 1. Mapping as the hardware-verified `rb-fpga/ref-repos` Sky Skipper
port.

## Switches

| Switch | Function | Down | Up |
|---|---|---|---|
| sw15 | audio | on | off |
| sw14 | amp gain | low | high |
| sw13 | display | 31 kHz VGA | 15 kHz TV |
| sw11-8 | DIP 1 (`sw1`) coinage DCBA, bits 3-0 | Dar's value (`"0000000"`) | bit inverted |
| sw7-0 | DIP 2 (`sw2`): cocktail / service2 / bonus / difficulty (3) / lives (2) | bit `'0'` | bit `'1'` |

DIP 2 is `sw(7 downto 0)`, not inverted; Dar's DE10 value `"00000010"` equals only sw1 up.
DIP 1 n.u. bits 6-4 fixed.

## Clocking

`clk_wiz_0`: 40.320 MHz (5 / 31.5 / 15.625), single domain, as Popeye (same TNX-1 board);
original 8.000 MHz crystal (CPU 4 MHz, AY 2 MHz). Video H 31.500 kHz / V 59.886 Hz (was
40.000 MHz: 31.250 kHz / 59.41 Hz, retuned 2026-10-01). Details:
`contrib/basys3/PORTING_SPEC.md` §2, `../CLOCK_CRYSTAL_CATALOG.md`.

## Building

Requires gcc, unzip, Vivado 2020.2, openFPGALoader. `make help`; `make` (setup, project,
patch), `make check` (parse-only), `make bitstream`, `make load` (existing bit),
`make rebuild-load`, `make clean`. `make setup` runs `contrib/tools/setup_sky_skipper.sh`:
verify the `dloads/` archive (SHA-256), extract `vhdl_sky_skipper_rev_01_2020_01_28/`,
apply `contrib/code/*.patch`, run `contrib/tools/prep_roms.sh` (romset pre/post-flight
checks).

## Known issues

## Issues addressed for Basys 3

- `rtl_dar/sky_skipper.vhd`: 4-bit `clock_cnt2` compared with `"10011"` never reloaded; CPU
  f/8, AY f/16 (+25%). Widened to 5 bits (`contrib/code/sky_skipper_clock_cnt2_width.patch`).
- Display mode on sw13 alone (2026-09-29); pristine `tv15Khz_mode <= not fn_toggle(7)`
  defaulted to 15 kHz.
- Keyboard on `clock_40`; the pristine 2 MHz `clock_kbd` was too slow for the onboard
  USB-HID host. Its `clock_div` counter remains as the PWM accumulator gate only.
