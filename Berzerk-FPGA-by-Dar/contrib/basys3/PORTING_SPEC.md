# Berzerk-FPGA-by-Dar — porting spec

Design record for the Basys 3 port. Procedure and conventions:
`../../../PORTING_SPEC.md`. Status: `../../README.md`.

## 1. Upstream and reference model

- Archive `vhdl_berzerk_rev_0_1_2018_08_08.zip` (SourceForge `darfpga/files/Software
  VHDL/berzerk/`), SHA-256 in `contrib/tools/setup_berzerk.sh`; extracted to
  `vhdl_berzerk_rev_0_1_2018_08_08/`. Core `rtl_dar/berzerk.vhd`; DE10 top
  `rtl_dar/berzerk_de10_lite.vhd`.
- MAME driver: `berzerk` (`stern/berzerk.cpp`).
- Model: Bagman-FPGA-Dar (same core-internal line-doubler video path), Pooyan conventions.
- Top entity `berzerk_basys3`; project `vhdl_berzerk_rev_0_1_2018_08_08/basys3/berzerk_basys3.xpr`.
- Project sources (`berzerk_basys3.xpr`):
  - `rtl_dar/`: `berzerk.vhd` (patched), `berzerk_sound_fx.vhd`, `berzerk_speech.vhd`,
    `gen_ram.vhd`, `io_ps2_keyboard.vhd`, `kbd_joystick.vhd` (unreferenced),
    `line_doubler.vhd` (instantiated inside `berzerk.vhd`).
  - `rtl_t80_304/`: `T80se.vhd`, `T80.vhd` (instantiated by `T80se` as `u0 : T80`; omitting
    it gave a synthesis black box), `T80_Pack.vhd`, `T80_ALU.vhd`, `T80_MCode.vhd`,
    `T80_Reg.vhd`. `T80_RegX.vhd` declares the same `T80_Reg` entity and must not be added
    (duplicate entity). `T8080se.vhd`, `T80a.vhd`, `T80sed.vhd` are unused variants.
  - `clk_wiz_0`; generated PROM VHDL in `tools/berzerk_unzip/`.

## 2. Clocking

- Original: 10.000 MHz crystal (MAME `MASTER_CLOCK`); Z80 2.5 MHz, pixel 5 MHz, S14001A
  2.5 MHz base.
- `clk_wiz_0`: request 10 MHz, achieved 10.000 MHz (2 / 15.625 / 78.125); signal
  `clock_10`. Speed error 0.
- Enables: inside the core; no separate sound clock (Z80, video, sound, PS/2 on
  `clock_10`).
- Video: pixel 5 MHz, h_total 320, v_total 262 → native H 15.625 kHz, V 59.64 Hz;
  31 kHz output H 31.25 kHz.

## 3. Reset

`reset <= btnC or not mmcm_locked`; MMCM reset = `btnC`. DE10 original: `reset <= not key(0)`.

## 4. Core instantiation

- Dar's `berzerk` entity (`berzerk.vhd:72-110`) unchanged apart from the Basys 3 actuals;
  `tv15Khz_mode => sw(13)` replaces the DE10 `sw(0)`.
- DE10-only debug ports dropped: `ledr` (only bit 0 driven, `led_on`), the core's `sw`
  input (debug only, tied low) and the `dbg_cpu_addr`/`dbg_cpu_di` 7-segment chain (gated
  by DE10 `sw(9)`).
- `video_r/g/b` and `video_hi` are 1 bit each; 4-bit expansion in the wrapper (§5).
- T80 (`rtl_t80_304/`) needs no width fix; synthesis clean (2026-10-01).

## 5. Video path

Core-internal line doubler (`berzerk.vhd:270`: `video_s <= video_o when tv15Khz_mode =
'0' else video_i`); no external scandoubler. 4-bit expansion as the DE10 top
(`berzerk_de10_lite.vhd:212-222`): `"1100"` when colour and `hi`, `"0100"` when colour
only, else `"0000"`; `blankn` is `'1'` there (no blank output). sw13: `0` = `hsync`/`vsync`;
`1` = `csync` on HS, VS `'1'`.

## 6. Audio

13-bit PWM accumulator on `clock_10`, DE10 slice (`berzerk_de10_lite.vhd:366-374`):
`'0' & pwm_accumulator(11 downto 0)` + `'0' & audio(15 downto 4)`; `O_PMODAMP2_AIN` =
bit 12. `SHUTD <= not sw(15)`, `GAIN <= not sw(14)`.

## 7. Inputs

- Keyboard: `io_ps2_keyboard` on `clock_10`, wrapper decoder (MAME keys,
  `../../../PORTING_SPEC.md` §3.1, §4.3), 2026-10-20: arrows, Left Ctrl = fire, 1/2 =
  start, 5/6 = coin. `kbd_joy` keeps Dar's `joyHBCPPFRLDU` order (`berzerk_de10_lite.vhd:
  183-198`): 0 up, 1 down, 2 left, 3 right, 4 fire, 5 start 1, 6 start 2, 7 coin.
  Replaces `kbd_joystick`.
- Core inputs: active-high; P2 mirrors P1 (`right2/left2/down2/up2/fire2`).
- Merge: `not jxadc_s(n)` OR keys; JXADC1/2/3/4/7 = right/left/down/up/fire; start 1 =
  key 1, btnL; start 2 = key 2, btnR; coin = keys 5/6, btnU, btnD.
- Synchronizers: 2-FF `ASYNC_REG` on PS/2, JXADC, buttons, on `clock_10` (2026-10-20).
- Debounce: none.
- Combos: none (fire+direction coin/start combos removed at the user's request; buttons
  added).

## 8. Switches and DIPs

| Switch | Core input | Bits | Default (down) | Notes |
|---|---|---|---|---|
| sw12 | `cocktail` | 1 | `'1'` (Dar) | `COCKTAIL_DEFAULT xor sw(12)`, 2026-10-20; inverted inside the core (`player2 <= not(cocktail & ...)`), upright level not verified |
| sw13 | `tv15Khz_mode`, sync mux | 1 | 31 kHz VGA | |
| sw14 / sw15 | PmodAMP2 GAIN / SHUTD | 1 / 1 | low gain / on | |

Fixed: DIP banks F2-F6 are constants inside the core (`berzerk.vhd:391-399`: F3 `X"BC"`,
F2 `X"FC"`, F4/F5/F6 `X"F0"`); need a core patch.
