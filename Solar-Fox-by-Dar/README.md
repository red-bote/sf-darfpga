# Solar-Fox-by-Dar

Basys 3 port of Solar Fox (Bally Midway, 1981), original core by Dar (darfpga@aol.fr),
<http://darfpga.blogspot.fr>. Source: `vhdl_solar_fox_rev_0_1_2019_11_22.zip` (rev 0.1,
2019-11-22), `dloads/`. Basys 3 port by Red~Bote. Dar's release notes: `README.txt` in the
extracted archive.

## Status

Hardware-verified 2026-10-20: picture (31 kHz VGA), sound, MAME keyboard decoder on
`clock_40`, JXADC joystick, buttons, coin 2. Earlier: USB-HID keyboard, buttons and
joystick confirmed 2026-09-25. Open items: none.

## Features (Basys 3)

- Video: native 31 kHz progressive or 15 kHz TV, generated by the core (no external
  scandoubler); sw13 up = 15 kHz TV (since 2026-09-28; the pristine F8 toggle had no
  power-on reset and could boot into 15 kHz, `../KNOWN_ISSUES.md`).
- Keyboard: onboard USB-HID port, MAME default keys, decoded in the wrapper (2026-10-20,
  replaces `kbd_joystick`; F0 = release, E0 ignored).
- Joystick: Atari-style on Pmod JXADC, pins 1/2/3/4/7 = right/left/down/up/fire, active
  low, pull-ups in the XDC.
- Audio: PmodAMP2 on Pmod JA pins 1/2/4; the core's stereo path, left channel out;
  `separate_audio` tied `'0'` (mixed, 2026-10-20; was the F5 toggle).

## Controls

| Action | Keyboard | JXADC | Basys 3 |
|---|---|---|---|
| move | arrows | pins 1-4 | |
| fire | Left Ctrl | pin 7 | |
| fast / start (`fast1`) | Left Alt | direction + fire | btnL |
| coin 1 / coin 2 | 5 / 6 | | btnU / btnD |
| service | F2 (toggle on press) | | |
| reset | | | btnC |

The core has no start inputs: `fast1` starts a game. Keys 1/2 are decoded but not
connected; btnR is unused. No player 2 / cocktail inputs. Mapping as the hardware-verified
`rb-fpga/ref-repos` Solar Fox port.

## Switches

| Switch | Function | Down | Up |
|---|---|---|---|
| sw15 | audio | on | off |
| sw14 | amp gain | low | high |
| sw13 | display | 31 kHz VGA | 15 kHz TV |

No DIP inputs at the core boundary: settings come from the service menu (F2).

| Basys 3 resource | Wrapper port | Function |
|---|---|---|
| clk (W5, 100 MHz) | `clk` | into `clk_wiz_0` |

| btnR | `btnR` | declared, unused |

## Clocking

`clk_wiz_0`: 40.000 MHz (1 / 10.0 / 25.0), single domain; original 19.968 MHz main
crystal, 16 MHz SSIO sound board. Video H 31.546 kHz / V 60.09 Hz (31 kHz mode). Details:
`contrib/basys3/PORTING_SPEC.md` §2, `../CLOCK_CRYSTAL_CATALOG.md`.

## Required ROMs

`solarfox.zip` (MAME romset; `ROMZIP`, default `~/roms/solarfox.zip`). Not included.
`prep_roms.sh` concatenates `sfcpu.*`, `sfsnd.*`, `sfvid.*` into `solar_fox_cpu.bin`,
`solar_fox_sound_cpu.bin`, `solar_fox_sp_bits.bin` and generates `solar_fox_cpu.vhd`,
`solar_fox_sound_cpu.vhd`, `solar_fox_bg_bits_1/2.vhd`, `solar_fox_sp_bits.vhd`,
`midssio_82s123.vhd` (`82s123.12d` is the same PROM as Kick's), referenced in place by the
project.
**Do not redistribute roms or anything generated from them.**

## Building

Requires gcc, unzip, Vivado 2020.2, openFPGALoader. `make help`; `make` (setup, project,
patch), `make check` (parse-only), `make bitstream`, `make load`. `make setup` runs
`contrib/tools/setup_solar_fox.sh`: verify the `dloads/` archive (SHA-256), extract
`vhdl_solar_fox_rev_0_1_2019_11_22/`, run `contrib/tools/prep_roms.sh`.

## Known issues

None open. Fixed: no sync on the Sylvania SF150 at power-on (15 kHz default),
`../KNOWN_ISSUES.md`.

## Issues addressed for Basys 3

- Display mode on sw13 instead of the F8 toggle (2026-09-28): `fn_toggle` has no reset in
  `kbd_joystick.vhd`, so the pristine top could boot into 15 kHz TV.
- Fast/start on a key and btnL: Left Ctrl from 2026-10-01, Left Alt since the MAME map
  (2026-10-20); pristine: Dar's `kbd_joystick` F-key map.
- `coin2` driven from key 6 / btnD (tied `'0'` before 2026-10-20).
- Keyboard on `clock_40`; the fabric `clock_kbd` (`clock_40`/6) is removed (2026-10-20).
