# Tron-by-Dar

Basys 3 port of Tron (Midway MCR, 1982), FPGA core by Dar (darfpga@aol.fr),
<http://darfpga.blogspot.fr>. Source: `vhdl_tron_rev_0_3_2019_11_22.zip` (rev 0.3,
2019-11-22), `dloads/`. Dar's release notes: `README.txt` in the extracted archive.

## Status

Hardware-verified 2026-10-20: picture (31 kHz VGA), sound, MAME keyboard decoder on
`clock_40`, JXADC joystick, buttons. DIP switches (sw12 cocktail, sw11 coin meters) wired
2026-10-20; cocktail with sw12 up not individually reported (Dar's DE10 top: cocktail mode
not supported). Earlier: USB-HID keyboard 2026-09-25. Open items: spinner on the joystick
(see Known issues).

## Features (Basys 3)

- Video: native 31 kHz progressive or 15 kHz TV, generated by the core (no external
  scandoubler); sw13 up = 15 kHz TV (since 2026-09-29; pristine: F8 toggle).
- Keyboard: onboard USB-HID port, MAME default keys, decoded in the wrapper (2026-10-20,
  replaces `kbd_joystick`; F0 = release, E0 ignored).
- Joystick: Atari-style on Pmod JXADC, pins 1/2/3/4/7 = right/left/down/up/fire, active
  low, pull-ups in the XDC. Movement and fire only.
- Audio: PmodAMP2 on Pmod JA pins 1/2/4; the core's stereo path, left channel out (as
  Kick); `separate_audio` tied `'0'` (mixed, 2026-10-20; was the F5 toggle).

## Controls

|---|---|---|---|
| move (8-way) | arrows | pins 1-4 | |
| fire | Left Ctrl | pin 7 | |
| spin left / right | Z / X | | |
| spin faster | Left Alt (held) | | |
| start 1P / 2P | 1 / 2 | | btnL / btnR |
| coin 1 / coin 2 | 5 / 6 | | btnU / btnD |
| service mode | F2 (toggle on press) | | |
| continue after game over | F6 (toggle on press) | | |

No player 2: the core has only cocktail-mode duplicates (`*_c`), tied off as in Dar's top.
The spinner (`angle`) is keyboard-only, as in Dar's DE10 top.

## Switches

| Switch | Function | Down | Up |
|---|---|---|---|
| sw15 | audio | on | off |
| sw14 | amp gain | low | high |
| sw13 | display | 31 kHz VGA | 15 kHz TV |
| sw12 | `cocktail` | upright (Dar `'0'`) | cocktail (not supported per Dar) |
| sw11 | `coin_meters` | Dar `'1'` | `'0'` |

No game DIP bank at the core boundary; settings via the service menu (F2).

## Clocking

`clk_wiz_0`: 40.000 MHz (1 / 10.000 / 25.000), single domain (core and sound board);
original 19.968 MHz main crystal, 16 MHz SSIO sound board. Video H 31.546 kHz / V 60.09 Hz
(31 kHz mode). Details: `contrib/basys3/PORTING_SPEC.md` §2, `../CLOCK_CRYSTAL_CATALOG.md`.

## Required ROMs

`tron.zip` + `midssio.zip` (MAME romsets; `ROMZIP` / `ROMZIP2`, defaults
`~/roms/tron.zip`, `~/roms/midssio.zip`). Not included. `tron.zip` lacks the shared Midway
SSIO PROM `82s123.12d`; `prep_roms.sh` takes it from `midssio.zip` and renames it to
`midssio_82s123.12d`. Generated PROM VHDL: `tron_cpu.vhd`, `tron_sound_cpu.vhd`,
`tron_bg_bits_1.vhd`, `tron_bg_bits_2.vhd`, `tron_sp_bits.vhd`, `midssio_82s123.vhd`,
referenced in place by the project.
**Do not redistribute roms or anything generated from them.**

## Building

Requires gcc, unzip, Vivado 2020.2, openFPGALoader. `make help`; `make` (setup, project,
patch), `make check` (parse-only), `make bitstream`, `make load`, `make clean`.
`make setup` runs `contrib/tools/setup_tron.sh`: verify the `dloads/` archive (SHA-256),
extract `vhdl_tron_rev_0_3_2019_11_22/`, run `contrib/tools/prep_roms.sh`.
`create_project.sh` stages only the `.xpr` and XDC (no scandoubler import).

## Known issues

- Spinner is keyboard-only (as Dar's DE10 top): `angle` is a 7-bit rotation value from a
  key-driven counter; the joystick has no analog equivalent. A JXADC approximation is an
  open option.
- Core-internal HDL 9-3240 CRITICAL WARNING (expression actual) at `rtl_dar/tron.vhd:945`,
  pre-existing in Dar's core; builds unaffected; left as is.

## Issues addressed for Basys 3

- Display mode on sw13 instead of the F8 toggle (2026-09-29).
- Reset held until the MMCM locks (2026-10-01; DE10 top left `locked` open).
- Keyboard on `clock_40`; the fabric `clock_kbd` (`clock_40`/6) is removed (2026-10-20).
- Midway SSIO PROM sourced from `midssio.zip` (absent from `tron.zip`).
